# Privacy Policy — FFXIclopedia Historical Viewer

FFXIclopedia Historical Viewer does not collect, sell, transmit, or retain personal information.

The extension stores only its own settings and revision-resolution cache using the browser extension storage APIs:

- enabled/disabled state
- cutoff date
- page-badge preference
- FFXIclopedia page title -> historical revision lookup results

When browsing FFXIclopedia, the extension sends requests only to FFXIclopedia's own MediaWiki API at `ffxiclopedia.fandom.com` to determine which historical revision should be shown.

The extension contains no analytics, advertising, telemetry, tracking code, remote executable code, or third-party service integration.
